# 3. 课程设计与真实运行

## 3.1 原始能力缺口

原 H1 是立方幂差的有限望远镜和。此前 matched 搜索中，模型能进入 induction successor residual，也能用 `ring` 正规化，但不能稳定把归纳假设用于消去两个 sum 后完成代数闭合；候选大量是裸 theorem 名、公式片段或重复的 `ring/omega/nlinarith`。

教师没有读取私有证明或给下一 tactic。课程只降低一个维度：把立方换成平方，保留 `Finset.range`、successor 展开、归纳假设和 ring 闭合这组真实接口。课程数量不预设；这门成功后先回原 H1，只有 trace 仍显示同一明确缺口才考虑下一门。

## 3.2 课程声明

```lean
def ChallengeV1.H1Curriculum.CourseSquareTelescope : Prop :=
  ∀ n : ℕ,
    (∑ i ∈ Finset.range n,
      (((i : ℤ) + 1) ^ 2 - (i : ℤ) ^ 2)) = (n : ℤ) ^ 2
```

完整声明随包位于 `config/ExecutionDeclarations.lean`，source SHA-256：
`6a27d4d7f9e1ae017fa998b95598396001530968844266e81dfde4f5805d3bdf`。

它不是首步 `simp` 题：需要组织有限和递推、Nat 到 Int coercion、归纳假设与环正规化，因此足以展示基本证明框架和题内学习，又没有把首例推到不必要的高难度。
