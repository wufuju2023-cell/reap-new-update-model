# 1. full-v3 value head 的训练

## 1.1 学习目标

训练目标不是无标度“好坏分”，而是从一个 Lean 状态沿已知成功树到证明终点的剩余步数。非终态标签裁剪到 1–64；证明终态由搜索协议单独定义为 0。搜索希望最大化效用，因此只在接入边界变号：距离越短，`-d` 越大。

这个语义与 AlphaProof 的负剩余步数思想一致，但本工程规模更小：先在冻结 7B 表征上监督训练小头，再用单题真实搜索轨迹做有界在线更新，不声称复刻 AlphaProof 的大规模自博弈系统。

## 1.2 数据与隔离

- train：205,628 个 LeanTree 状态；原 80,000 加新增 125,628，全部使用。
- validation：8,000。
- test：8,000，只用于最终评估。
- sample、state、root theorem 与 theorem family 四层跨 split 隔离。
- 80k 头只保留作历史消融，不进入本案例正式训练。

每个状态由同一冻结 REAL-Prover 7B encoder 提取 3,584 维特征。跨平台部署前，冻结 base 的 339 个张量按 name/shape/dtype/规范化 CPU 原始字节逐项比较，差异为 0；platform-local runtime digest 只作审计，不冒充跨平台模型身份。

## 1.3 模型结构与优化

```text
hidden state (3584)
  -> Linear(3584, 256)
  -> SiLU
  -> Linear(256, 64)
  -> logits over distance bins 1..64
```

总参数 934,208。离线训练使用 unweighted categorical cross entropy、AdamW、学习率 `1e-3`、weight decay `0.01`、seed `20260829`、batch size `4096`，最大 30 epochs 并按 validation early stopping。推理时：

```text
p = softmax(logits)
d = Σ(k * p[k]), k=1..64
V = -d
```

正式随机对照不是任意另一模型，而是同一结构、同一 seed、训练前精确初态 `R64-v3`。

## 1.5 为什么使用 64 档 categorical head

相比单 scalar，64 档概率分布保留了距离不确定性；期望值仍给 MCTS 一个可解释标量。在线 fractional target 可以投影到相邻两个 bin，形成 two-hot categorical target，而不必伪造整数标签。代价是 64 截断以后长距离区分变弱，分布外状态仍可能过度乐观，因此必须用真实搜索轨迹和 Lean 结果审计。
