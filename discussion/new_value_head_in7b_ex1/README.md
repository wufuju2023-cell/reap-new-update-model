## 核心语义

```text
非终态距离：d ∈ [1,64]
搜索效用：V(s) = -d
已证明终态：d=0, V=0
Lean 非法动作：丢弃
形式化确认的死节点：-∞
预算耗尽或未找到证明：unknown，不是 -∞
```

模型头为 `3584 → 256 → 64`：对 64 个距离档输出 logits，softmax 后取期望得到正距离 `d`。MCTS 只在接口处使用 `-d`。REAL7B 路线的题内 TTT 会联合更新 policy LoRA 与 categorical value head；更新必须有真实参数/optimizer 变化、版本递增，并被后续生成和 value 前向消费。

## 已完成的展示结果

`CourseSquareTelescope` 在 Radeon 的 REAL7B/full-v3 上于 checkpoint 20 自然证明成功：step 7 和 step 15 两次联合 TTT 分别得到 v1、v2，更新后继续搜索，成功路径后 3 步由 v2 生成；完整 proof 通过固定禁网 Lean 验收。终端成功轨迹更新至 v3 后，session 已 seal、发布 experience `exp-078cea5460cb-01` 并 receipt-backed retire。

该案例证明 full-v3 课程/MCTS/TTT/Lean 闭环真实可运行。它没有同题随机臂，因此不单独证明因果优势；F1 matched pair 承担这一比较证据。
