# Full-v3 课程学习、行为监控与原题回归

状态：2026-08-29 阶段冻结中。本文件描述当前最高优先级的成功闭环，不把未闭合运行包装成展示案例。

## 1. 目标

在一题有实际结构、但不是 IMO 级超难题上展示：

```text
学生可见原题
-> 先跑 full-v3 MCTS+联合TTT，定位真实能力缺口
-> Codex 设计最小充分课程
-> 每课真实搜索与多次 LoRA+categorical-head 联合更新
-> 完整学生proof通过固定CPU/network=none独立Lean
-> 成功子课proof成为后续学生可见定理
-> 回到原始题面并完成完整证明
-> snapshot/retire/证据SHA与复现说明
```

当前原题是 `ChallengeV1.H1`：有限 `Finset.range` 上相邻立方差的望远镜和。它有归纳、求和展开、整数 coercion、IH 重写和代数闭合等真实接口，但不要求复杂外部工具，符合“不能太简单、优先跑通”的定位。

## 2. 当前诊断

matched pair 证明模型已能进入合法 induction succ residual。主要缺口不是选择归纳，而是把以下动作组合成正确 Lean tactic：

```text
Finset.sum_range_succ
-> 用 induction hypothesis 重写并消去前缀和
-> ring/规范化闭合剩余立方恒等式
```

full-v3 会更早回访正确归纳链，但在归一化残式上重复产生裸 theorem 名、公式片段和无效 `ring/omega/nlinarith`。旧运行的在线 LoRA/value-head 更新真实发生并被后续 generation 消费，但 `selection_value_refresh=false`，旧节点缓存没有重评分；因此新课程 family 必须显式启用 refresh，不能沿用这个缺口。

## 3. 最小初始课程

课程设计任务：`01a04d6d-73b2-7802-ad54-befaaa84d506`。

初始最多两门组合课，不照搬 IMO 长课程链：

1. **平方差完整望远镜**：用较低代数难度练习完整的 `sum_range_succ -> IH -> ring` 组合。
2. **给定 IH 的立方 successor bridge**：直接训练 H1 缺失的单个归纳步，但不等价重写整道 H1。
3. **原 H1**：保持原声明字节和数学内容，不人工续写。

课程数量由行为决定：若第一课已经稳定生成并使用完整组合动作，不再增加同类简单课；若一个完整监控窗口仍显示唯一明确缺口，才结束当前 frozen family，另立新 family 增补一门。运行中的 course plan 不热改。

## 4. 成功子课作为定理

用户允许最终原题显式使用成功子课。每个子课只有通过以下门，才可进入累积学生定理库：

1. 模型生成完整 proof；
2. 固定 CPU、`network=none` 独立 Lean 通过，并检查公理；
3. 保存 theorem name、type、完整学生 proof、source/input SHA；
4. 真实 success replay learn 与不可变 experience 发布完成；
5. 下一 session 核对 experience lineage、fresh optimizer/version；
6. 生成的学生输入明确包含该 theorem/interface；
7. trace 区分“环境可见”和“后续 proof 真实引用”。

定理库辅助与参数迁移分开报告。不得使用 `axiom`、`sorry`、教师 proof 或近等价整题答案。

## 5. REAL7 正确在线更新合同

- 离线 categorical head 输出 `d∈[1,64]`；MCTS 使用 `V=-d`。
- 有效 OR 节点的 `search_visit_backup` 给出有限距离 target；裁剪到 `[1,64]` 后做相邻档 two-hot categorical cross entropy。
- AdamW 同时更新 policy LoRA 与 categorical value head，并含对冻结 base 的 KL 约束。
- 每次 learn 必须核对 adapter、value head、optimizer 实变、base 冻结和版本递增。
- 新 family 必须启用 `selection_value_refresh=true`：learn 后刷新已缓存节点 value，再由后续 generation 消费同一新版本。
- 成功后的 terminal learn 单列；未被后续搜索消费，不能解释本次证明。

## 6. 行为监控与有界早停

只读监控任务：`01a04d75-3382-75e1-af12-313ef1d61523`。规则文件位于 `../experiments/fullv3_behavior_monitor/README.md`，SHA-256 `1e95659cd49f0dee2e693c7b0938d01d5bafee56a45d20263e8f46ba482752f8`。

监控每个完整 8-checkpoint/update 窗口最多给一次建议，不直接操作 session。除工程/合同安全错误外，只有同时满足以下条件才建议早停：

- 至少 16 checkpoints；
- 至少 2 次联合 learn 已被后续 generation 消费；
- 连续两个完整 update interval 没有新合法非重复节点；
- 最深残式没有结构变化；
- 主要候选持续重复、merged 或非法；
- 没有未访问的高分合法候选，也没有首次正确使用已验证定理。

如果刚出现新的结构动作、闭合子目标、正确引理调用或未访问高分合法候选，至少继续一个有界窗口。安全停止必须在 checkpoint 边界，核齐 learn receipts、actor active/queued=0，再 snapshot 和 retire；失败参数不发布。
