# 设计说明

这里回答“为什么这样设计”，不记录某次运行的偶然时间线。

推荐顺序：

1. `00_术语表.md`：先统一 value、distance、MCTS、TTT 等词的含义。
2. `01_Value设计与评价方法.md`：理解训练数据、64 档头、搜索接入、在线更新与评估门。
3. `02_课程学习与动态调度.md`：理解失败后如何设计最小课程、何时早停、何时回原题。

设计中有两类内容：

- 不可变语义：正剩余距离、搜索使用负距离、Lean 非法动作丢弃、预算耗尽为 unknown、独立 Lean 才能确认 proof。
- 当前工程取舍：64 档截断、冻结 7B 表征离线训练小头、单题联合 LoRA/value TTT，以及当前 stable runtime 关闭旧节点 selection-value refresh。

后者可以升级，但升级必须重新建立 runtime 合同和因果实验，不能悄悄改写已运行案例。
