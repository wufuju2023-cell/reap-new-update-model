# 从已验证证明中提取步骤并训练

## 输入、过程与结果

输入是三份模型生成的成功证明。独立Lean检查不仅验证整个定理，还逐步执行原证明，核对每一步之前和之后的证明状态，得到11条可用于训练的证明步骤。完整原始材料包含三份各17文件的数据包。

这些步骤用于一次真实7B策略与价值头联合更新。冻结基座不变、会话隔离和完整恢复等17项检查通过。价值目标来自已经验证的剩余证明步骤数；本阶段没有新的解题效果对照。

## 核查文件

| 文件 | 核对内容 |
|---|---|
| [report.json](files/report.json) | 17项真实GPU验收检查；字段`ok`、`gates`、`schema_version` |
| [artifact-audit.json](files/artifact-audit.json) | 运行代码与持久产物hash；字段`schema_version` |

## 原始材料的使用

[manifest.json](manifest.json)记录原始来源、文件大小和SHA哈希；[raw.zip](raw.zip)保存清单内完整原始材料。`files/`提供JSON与Lean文件的阅读副本。需要重新审计或加载训练数据包时，先按清单校验压缩包，再解到新的目录；加载器需要完整数据包，不能仅使用阅读副本。

模型权重、大型适配器及优化器快照、浏览器凭据均未打包。报告中的张量结论来自当时源码已固定的GPU程序，可按哈希追溯；阅读或校验这些文件不会触发训练。
