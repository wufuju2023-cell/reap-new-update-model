# 终态快照复用

## 输入、过程与结果

输入是已经训练、并从快照完整恢复的7B会话。程序先保存终态快照；在同一个运行进程中确认此后没有会话操作改变状态，再复用该快照释放会话。

真实GPU检查中，释放过程没有再次导出参数，已释放的容量可以创建新会话，原快照保持不变。本阶段直接调用运行时接口，没有做新的训练或HTTP整链路验收，也没有对照试验可用于量化吞吐收益。

## 核查文件

| 文件 | 核对内容 |
|---|---|
| [report.json](files/report.json) | 实际释放会话与状态检查；字段`ok`、`gates`、`schema_version` |
| [evidence-receipt.json](files/evidence-receipt.json) | 证据引用与哈希 |

## 原始材料的使用

[manifest.json](manifest.json)记录原始来源、文件大小和SHA哈希；[raw.zip](raw.zip)保存清单内完整原始材料。`files/`提供JSON与Lean文件的阅读副本。需要重新审计或加载训练数据包时，先按清单校验压缩包，再解到新的目录；加载器需要完整数据包，不能仅使用阅读副本。

模型权重、大型适配器及优化器快照、浏览器凭据均未打包。报告中的张量结论来自当时源码已固定的GPU程序，可按哈希追溯；阅读或校验这些文件不会触发训练。
