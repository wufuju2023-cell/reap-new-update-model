# 最新发布版本与双服务衔接：本地机制

默认的固定版本模式保持不变。显式提供最新版本选择器`ReleasedAttemptProvider(learner)`后，服务池绑定指定学习任务及完整模型配置，每个新尝试预约该任务最新已确认的发布版本，并在整个尝试中保持不变。

本地测试使用持续学习器和小张量。第一次优化更新发布第一版参数；加入一份已验证的测试数据后，第二次更新发布第二版。两个独立模型实现通过真实HTTP服务分别持有私有会话：旧会话仍在运行时，新会话在另一服务准确加载第二版适配器和价值头，旧会话的参数和题内版本均保持不变。

Windows50项全部通过；WSL43项通过、7项因缺少Torch跳过。7份源码在测试前后哈希一致。发布结果未知、只有参数文件却没有发布确认、来源不属于指定任务或配置不匹配时，系统均拒绝使用。已完成任务重新打开时不会重新训练。源码、日志及回执见[完整原始包](raw.zip)和[成员清单](manifest.json)。

本阶段只是本地小张量机制验收。真实7B双服务Lean搜索采用固定参数版本，见[真实链路](../replica-collector/README.md)。后来最新版本与双服务的联合GPU运行整体失败，见[失败记录](../latest-release-gpu/README.md)；不重新训练的独立恢复消费另行[通过验收](../latest-recovery-gpu/README.md)。这两段结果不能合称原联合运行通过。
