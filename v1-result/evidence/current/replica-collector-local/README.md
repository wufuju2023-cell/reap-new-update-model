# 双服务固定路由本地机制验收

本阶段实现固定参数版本的双服务调度。每题开始前先保存不可变的服务分配记录，再向选定服务请求搜索。搜索明确结束后提交会话释放请求，只有释放回执核对并落盘成功，才把容量交给下一题。创建、搜索或释放结果未知时保留占用并停止新派发，不切换服务重试。每个服务内部仍串行保护可变适配器和会话随机状态。

最终版本共33项测试，其中14项检查服务分配、19项检查已有的有界批处理，在Windows、WSL均通过。单测报告耗时分别为7.609、5.634秒；从启动到退出的进程耗时分别为7.907、6.406秒。测试覆盖12次完成尝试、两个实际HTTP简化模型服务、并发执行、释放后补位、未知结果的安全收束、恢复时禁止重复发送，以及来源和私有状态隔离。没有执行GPU计算或Lean数学验收。
