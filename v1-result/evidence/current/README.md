# 当前实验的证据导航

这里保存当前报告引用的小型原始材料。先读[实际实例](../../docs/current/04-实际实例与验收结果.md)，再按需要查看下面的阶段说明。

每个阶段的`raw.zip`保存该阶段清单内的完整文件；`files/`仅提供便于阅读的副本，可能省略长路径文件。证明数据的完整验证需要从归档解出17文件或22文件的数据包，不能直接把精简副本目录交给读取程序。`manifest.json`记录来源、每个成员及其内容哈希。

## 复核边界

本地机制、真实7B、独立Lean和长期运行分别报告。每次实验使用自己的冻结源码，保留当时路径、时间、成功、失败和继续点；当前工作源码不能替代历史实验的代码身份。

权重和大型张量快照不在本包。无需GPU即可核对归档与成员哈希、读取证明和收据；实际张量复检或重新训练需要对应的远端资产与环境。

复现入口见[源码与脚本](../../source/current/README.md)，整体说明见[总设计](../../docs/current/00-总设计与阅读地图.md)。
