# 给新同学和新Agent的入口

这个目录适用于第一次接触项目、在另一台电脑上开始复现的同学。

1. 将整个`v1-result`目录放到电脑上，保留内部结构。
2. 将[新Agent交接prompt](01-新Agent交接prompt.md)全文复制到新对话，填入本机报告的绝对路径。
3. 想先了解原理，按[教学目录](教学/README.md)阅读；准备动手时进入[代码与复现](../reproduction/README.md)。

prompt用于交代项目和工作顺序，教学文档解释原理，复现目录提供代码、原题、命令和验收方法。模型权重、容器镜像和历史大快照需要另外准备；新对话不会继承原电脑的登录、路径或运行状态。
