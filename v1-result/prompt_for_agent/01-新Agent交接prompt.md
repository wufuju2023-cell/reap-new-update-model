## 项目与实验目的

项目主体是数学证明的测试时训练框架（TTT）：模型在解题过程中继续学习，将学到的参数用于后续搜索和新题。我们使用Reap作为树搜索组件，使用Lean检查证明；在它们外围实现训练、版本确认、跨题经验继承、并发调度和状态保存。基础模型为固定版本的REAL-Prover，约70亿参数。训练保持基础参数冻结，更新少量附加参数及价值网络。

CPU运行Lean和Reap，维护每道题的搜索树，检查模型给出的候选步骤，收集搜索反馈。GPU运行7B模型，生成证明步骤、评价状态，并执行训练。最终证明在独立断网的CPU容器中重新检查。

当前有两条已实施的学习路线：

1. **同一题边搜索边训练。** 搜索积累候选访问次数和状态评价；暂停本题搜索，提交一次训练；GPU确认新版本后，由同一个Lean进程沿原树继续。整题尚未完成时，最终成功奖励为0，仍可用搜索访问比例及搜索估值训练。
2. **已验证证明的集中学习。** 搜索端在一次尝试中固定参数；证明成功并通过独立复验后，逐步记录“证明状态—下一步动作”，用于集中训练和参数发布。已经验证过的混合训练每批使用9条模型生成步骤和1条数学库原有步骤。采样按步骤计算，数学库原有证明保留原文，Codex编写采集与核查脚本。

跨题复用传递的是已验收的附加参数及价值头。新题有自己的优化器、随机状态、缓存、更新计数和搜索树，来源参数不会被改写。不同题可以同时搜索。若明确要求题2使用题1刚学到的参数，题2的初始化必须等待该经验发布；没有这项依赖的任务可以继续并行。
