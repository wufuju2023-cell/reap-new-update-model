1. [整体流程与CPU/GPU分工](01-整体流程与CPU-GPU分工.md)：输入、搜索、模型计算、训练、证明检查分别发生在哪里。

3. [跨题经验、版本与并发](03-跨题经验版本与并发.md)：新题继承哪些内容；什么时候需要等待；两个模型服务怎样同时支持搜索。
4. **[跨题经验的设计与代码实现](05-跨题经验的设计与代码实现.md)**：从题A的训练结果到题B的初始化，逐项对应实际参数、三个来源标识、发布与创建接口、检查条件和源码函数。
5. [成功实例与复现检查](04-成功实例与复现检查.md)：沿具体实验理解每项设计实际完成了什么，以及如何检查自己的新运行。
