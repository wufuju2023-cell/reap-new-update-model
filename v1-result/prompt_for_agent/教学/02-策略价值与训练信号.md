# 策略、价值与训练信号

## 一个模型的两项工作

**策略网络生成下一步证明动作。** 输入是当前Lean证明状态，输出是动作文本及其生成概率。Reap调用Lean检查候选，搜索再决定继续尝试哪些分支。

**价值网络评价当前状态。** 它读取7B模型对证明状态的内部表示，经过一个小型网络给出估值。搜索可以据此分配有限的尝试机会。估值是一项模型判断，完整证明由Lean检查。

当前两者共用7B基础模型。训练冻结基础参数，更新少量附加参数（LoRA）和价值头。因此，每道题可以保存自己的小规模训练状态，并与其他题隔离。

## 题目尚未解出时的策略目标

搜索会记录各个候选动作被访问的次数。训练将访问次数归一化为比例，让策略网络学习搜索尝试的分配。

假设两个合法候选分别访问8次和2次，训练比例就是80%和20%。这组数字只作示意。访问分配同时受已有模型判断、估值和探索机制影响，尚未找到完整证明也能形成这些统计。

其简化目标可以写成：

`策略损失 = −Σ（候选访问比例 × 模型生成该候选的对数概率）`

框架还约束训练后分布偏离基础模型的程度，并检查动作来源、搜索树、节点、版本及数值是否合法。只有通过检查的搜索反馈进入训练。

## 题目尚未解出时的价值目标

搜索先使用价值网络对未解决状态作估计，再结合后续分支与子目标情况，将评价向树上层汇总。训练读取节点累计值和访问次数，恢复搜索估计的平均距离，再按固定折扣系数转换为价值目标。

以折扣系数0.99为例，距离估计为d时，目标值为`0.99^d`。这个目标来自搜索估计，尚未掌握真实完整证明长度。

**整题未完成时，最终成功奖励为0；当前题内损失直接使用访问比例和搜索估值，不再乘这个成败字段。** 因而不会把所有中间状态的训练信号同时抹为0。

## 三次更新实验中的第一次训练

奇数累加题在搜索第8步仍未证明，第一次训练记录为：

- 策略候选是`intro n`，含义是引入变量n；只有这一个候选被访问，目标占比为100%。
- 节点累计值约为−584.086884，访问9次，恢复出的距离估计约64.8985。
- 价值训练目标为`0.99^64.8985 ≈ 0.52613`。
- 当时整题成功奖励仍为0。

这一轮让策略学习已探索过的合法动作，让价值网络拟合搜索汇总后的评价。搜索随后又训练两次，并用第三次更新后的参数完成证明。该实验跑通了训练与原搜索接续的循环；原始数值见[参数与训练目标检查](../../evidence/multiround/snapshot-audit.json)，过程见[具体例子](../../docs/current/04-实际实例与验收结果.md#same-tree-three-updates)。

## 已验证证明的训练目标

集中训练使用已经完成并通过Lean检查的证明。逐步重放会得到若干条记录，每条是“动作前的证明状态—下一步动作”。

策略部分学习在该状态生成那个已验证的动作。价值部分学习这条成功证明中剩余动作步数的类别；分成多个子目标时，按最长必要分支统计。这里依据的是已经验证过的证明步骤，和前面的搜索估值路线有不同含义。

本轮混合训练每批使用9条模型生成步骤和1条数学库原有步骤，每条权重相同。同一份证明可以产生多条训练记录，9与1是步骤数。数学库材料来自固定Mathlib文件的三份原有证明，Codex编写采集与核查程序。

两条路线的价值网络输出形式、目标和兼容条件不同。题内经验由对应题内服务使用，混合训练发布结果由对应的混合服务使用；加载器检查基础模型、训练目标及参数形状等条件。复现命令已分别指定服务类型，见[代码与复现](../../reproduction/README.md)。
