## 3. AlphaProof 论文与本项目的关系

| 论文相关环节 | 当前状态 | 区别与边界 |
|---|---|---|
| 已验证的证明或反证用于训练，失败不进入成功回放 | 真实采集正向证明和反证，独立验证后逐步回放；[实例](04-实际实例与验收结果.md#proof-and-disproof) | 失败保留归档；独立的搜索监督分支仍可用未解题的搜索反馈训练 |
| 根据状态和正确动作训练策略，根据实际回报训练价值 | 独立`verified_success_replay`已在真实7B上通过 | 分类范围、结束标记、LoRA、负最长动作分支和价值读取位置均明确固定，不宣称与论文每个细节相同 |
| 学习器训练，搜索服务消费发布版本 | 已完成“发布→新题证明→验证→回流训练”；另一次实验完成两次训练和发布，为新任务预约第二版参数；随后从快照恢复仍使用第一版的旧任务，让新任务使用已发布的第二版，[实例](04-实际实例与验收结果.md#published-version-recovery) | 原自动发布运行退出1；后续恢复通过，未重训或重新发布。未知发布封锁仅本地故障测试通过；完整自动选最新版的Lean批次和长期集群未验 |
| 90%生成证明回放，10%数学库原有证明 | 每批9条生成证明步骤＋1条库中原有证明步骤，每条记录的损失权重均为0.1；两次真实更新通过 | 比例按步骤记录数，不按题数；库中证明同时训练价值是工程选择。这两次更新只采到2条不同的库中原有证明步骤 |
| 跨阶段继承并加入新成功数据 | 持续学习模式实际完成来源参数继承、第一次更新后的完整恢复、新数据采样和第二次发布 | 原有第二版数据格式的产物只读保留；新增证明由先前发布的第二版参数生成，此次继续学习使用已验数据，没有重新搜索 |
| 目标相关变体课程与专门训练 | 用户已暂停，暂存模块未接入本轮 | 通用学习器和两个独立命题不构成目标变体课程 |
| 大规模持续自改进与效果 | 尚无结论 | 本轮验证有限机制与短期稳定性，不追加效果对照 |

数学库数据取自固定Mathlib版本的原有证明。Codex编写采集和核查脚本；辅助包装没有进入训练数据，原证明来源不归于采集脚本。

第11–13篇的自博弈与教师演化、旧第5–8篇的元编程、工具效应、语言塔和V2记忆属于后续扩展。本项目“v3”只是持续学习数据格式的版本号，不表示这些扩展已实现。

当前构建源码见[CPU目录](../../source/current/README.md)（解包后`containers/cpu`）、[GPU Containerfile](../../source/current/README.md)（解包后`containers/gpu/Containerfile`）、[GPU hashed依赖](../../source/current/README.md)（解包后`containers/gpu/requirements-gpu-hashed.lock`）。新配方为`containers/gpu/Containerfile.runtime`，基础digest固定，22份hash wheel离线安装，镜像实际构建exit0；本地容器核对30份源文件和三session回收通过。见[镜像与容器验收](../../evidence/current/gpu-runtime-image/README.md)。AMD实例无可用Docker daemon和相应平台能力，容器内训练保持待验。
