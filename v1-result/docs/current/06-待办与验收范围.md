- **持续混合学习。** 来源参数继承后，实际完成两次训练；在两次训练之间完整恢复，并在第二次采到新增的成功证明步骤。两代模型发布及隔离检查共16项通过，见[持续学习实例](04-实际实例与验收结果.md#continued-learning)和[原始证据](../../evidence/current/continual-mixed/README.md)。

- **发布结果未知时保护。** 本地小张量事务测试确认：阻止新训练和新预约，不自动重复执行，已固定版本的旧题可继续。该故障没有在本次GPU实验中注入。
- **当前交付。** 已整理主报告、188文件源码、小型证据和复现脚本；580项核心、71项工具和44项交付脚本回归完成。具体通过、跳过及失败记录以各测试收据为准；最终包还须通过清单、归档及链接检查。

**GPU容器的状态单列。** 29.82GB运行时镜像已实际构建，断网、只读、UID10001容器检查通过；AMD容器内真实推理和训练仍未验。已完成的7B实验运行在远端宿主隔离环境。容器训练属于实验后的尽力项，不计入本轮2.5小时收尾范围，见[构建与容器证据](../../evidence/current/gpu-runtime-image/README.md)。

## 4. 后续实验与记录要求

先看已有证据，再定义一个明确的新增验收点。新实验使用新目录和固定输入，保留实际失败。训练结果未知时核对原请求编号、启动意图和收据，不自动重训。搜索结束后先保存结果和模型状态，确认会话已释放，再独立验证证明。

本地机制、真实7B、独立Lean和长期运行分别报告。当前源码与各次实验的冻结源码分别标识，历史证明、失败和原始报告保留在[归档](../history/archive-manifest.json)。

复现环境以[源码指南](../../source/current/README.md)和[容器说明](../../docker/README.md)为准。CPU使用固定Lean工具链；GPU实验的模型、依赖和运行方式须与记录匹配。权重及大型训练快照不随小型证据包提供，恢复前先确认所需资产仍存在。
