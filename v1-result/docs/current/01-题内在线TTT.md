# 题内搜索与训练循环

## 输入与本题状态

这条路线让模型在当前题目尚未解出时利用搜索反馈训练，再继续原来的搜索。需要提供题目、搜索和训练预算、模型配置，以及可选的经验来源。

新题可以从基础模型开始，也可以复制一个已验收的经验版本。程序先检查来源是否兼容，再为本题建立独立的可训练参数、优化器、随机数状态和训练缓存。本题更新次数从v0开始；其他题不会随它改变。

## 一次完整循环

1. CPU启动Lean和Reap搜索树。模型根据当前证明状态提出候选步骤，并给出状态估值。
2. Lean尝试执行候选，Reap记录访问次数、成功或失败的分支，以及向树上层传回的估值。
3. 到达训练检查点时，程序检查是否有合格数据。没有就继续搜索；有就暂时停住本题的树，提交一次训练。
4. 更新通过检查并保存后，服务返回新版本确认。本题从v0变为v1，再由同一个Lean进程、同一棵树继续搜索。后面可重复这个循环。
5. 找到完整证明或用完预算后，保存结果。配置了资源回收时，确认释放本题模型状态，再用独立的断网Lean环境复验完整证明。

因此，一次训练不会重新开题，也不会清空搜索树。已经发生的探索保留，后续模型请求使用确认后的新版本。具体例子见[三次更新后完成证明](04-实际实例与验收结果.md#same-tree-three-updates)。

## 搜索反馈与训练目标

这里使用搜索反馈训练方式（search_visit_backup），包含两个目标。

**学习哪些步骤更值得生成。** 将候选步骤的访问次数归一化，用这个比例训练候选文本的生成概率。访问次数较多的候选获得较大的训练权重。这里的访问统计来自当前搜索，并不要求已经找到整题证明。

**学习当前状态的估值。** 从节点累计值和访问次数恢复搜索估计的平均距离，再按固定折扣系数转换为价值目标。价值头学习这个折扣后的数值；它代表搜索估值，不能当作已经知道的真实剩余证明长度。

两项训练都只更新本题的小规模附加参数和价值头，基础模型保持冻结。训练还约束新分布偏离基础模型的程度（KL约束）。树、节点、输入状态、候选来源版本、当前版本、折扣系数和数值范围都要通过检查；不合格的记录拒绝使用。

### 未完成证明时的训练信号

当前损失直接使用候选访问比例和搜索估值，不乘最终成败字段。因此，整题尚未证明、该字段为0时，仍能学习搜索反馈；没有给每个中间动作额外标注“成功奖励”。

三次更新实验的第一次训练发生在搜索第8步。该条记录只有候选“intro n”，访问1次，所以策略目标为100%；这次训练提高的是这一合法步骤的生成概率，没有比较多个候选的优劣。节点累计值为−584.086884，访问9次，估计距离约64.8985；按0.99的折扣系数换算，价值目标约为0.52613。[原始数值与检查](../../evidence/multiround/snapshot-audit.json)保留了这次计算依据。

没有访问的节点、已经解决的节点和仅用于切换子目标的占位统计，不当作普通训练记录。候选产生时的旧版本信息保留；这套训练是在学习搜索统计，没有使用其他算法中的新旧策略概率比。

## 原搜索树使用更新后的估值

默认情况下，历史访问次数和累计统计保留，之后的模型请求使用新版本。可选的选择估值刷新（selection-value-refresh）会在更新确认后，重新评估已经访问但尚未解决的状态，供下一次选择分支时使用；有多个子目标时，按约定汇总其估值。

这个功能已有一次真实实验：更新后刷新两个状态，再用新版本生成后续步骤并完成证明。它只更新选择用的缓存，历史访问次数、训练目标和原候选的先验权重保持不变；没有重新计算整棵树的所有历史统计。见[选择刷新证据](../../evidence/current/selection-refresh/README.md)和[其他模块验收](04-实际实例与验收结果.md#other-checks)。

## 失败处理与跨题经验发布

训练前保存完整的更新前状态。能够确认的更新失败按事务规则恢复，并向搜索端返回错误、停止该树；如果提交结果未知，则保存原操作标识，查询已有执行结果，不自动再训练一次。磁盘提交未知也不能仅凭内存状态判断成功。

可选的更新后约束会先尝试更新，再在正式提交前检查偏离程度，超限就拒绝并恢复。真实7B已分别验证接受与完整回滚；该试验直接调用训练程序，使用旧搜索事件回放，不属于一次新Lean解题。见[约束接受与回滚证据](../../evidence/current/kl-guard/README.md)。

本题训练完成后，若希望另一题继承，需要另外验收来源并发布不可变参数。新题只复制获准参数，优化器等私有状态重新建立。已有三题从同一来源初始化，分别更新4、1、1次后完成证明，见[跨题继承实例](04-实际实例与验收结果.md#cross-problem-inheritance)。另一条使用成功证明训练的路线，价值头采用不同含义，详见[中央训练](02-跨题经验与中央学习.md)，不能直接混用。

## 对照代码

[源码与复现入口](../../source/current/README.md)解包后，本题协调程序为cpu_runtime/online_ttt.py，多题入口为cpu_runtime/online_batch.py；训练目标和后端分别在gpu_runtime/search_objective.py、gpu_runtime/search_backend.py，状态提交与恢复在gpu_runtime/runtime.py。历史实验以各自冻结版本和[原始证据目录](../../evidence/current/README.md)为准。
