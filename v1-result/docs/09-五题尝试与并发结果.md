# 五题尝试、在线多轮更新与并发结果

## 这次完成了什么

本次测试 **5 道不同的自然数递推题，共 8 次 session 尝试**。最终 3 道证明成功，2 道在 32 步搜索后仍未证明。成功题中，01 经 **3 次在线更新**，05 经 **2 次在线更新**；每次更新时搜索尚未证明完成，后续生成实际使用了新版本，最终证明均通过独立离线 Lean 编译。

重点看 01：训练发生在证明搜索尚未完成时。它在 step 8、9、10 分别更新到 v1、v2、v3，随后 step 11 使用 v3 继续生成，最终完成证明。请求/响应、参数哈希链、真实首末快照和原题证明复核已交叉核验。

这完成了“两道题各自至少两次在线更新后证明成功”的验收。初次批次也有多个搜索同时推进的证据；本页不将两个成功重试描述成同时完成多轮训练的成功批次。

## 成功证明及独立复核

01 给定 `f 0 = 1`、`g 0 = 0`、`f(n+1)=f n+2`、`g(n+1)=g n+f n`，证明 `f n=2*n+1 ∧ g n=n*n`。生成证明：

```lean
intro n
induction n <;> simp_all [hfstep, hgstep]
ring
next => simp
```

05 给定 `f 0=0`、`f(n+1)=f n+(n+1)^3`，证明 `4*f n=(n*(n+1))^2`。生成证明：

```lean
intro n
induction n <;> simp_all [hzero, hstep]
ring_nf
linarith [hzero, hstep]
```

03 证明带参数的三角数公式 `2*f n=2*a+b*n*(n+1)`，使用 `intro`、`induction`、`simp_all`、`linarith`。

三份复核文件都由原题直接替换搜索入口得到，随后追加 `#print axioms`，题目和假设不变。01/05 在两个禁用网络的本地 CPU 容器中并行独立编译；回执和 container inspect 均确认固定镜像、`network=none`、退出码 0，无 `sorryAx`。复核耗时分别 **52.303 秒、53.276 秒**；03 的独立复核为 **10.609 秒**。这些都是搜索后的证明复核时间，不计入 TTT，也不能直接比较为单独运行性能。03 的旧复核记录提供执行回执，没有额外 container inspect 文件。

## 更新真实性与并发边界

01r1 的 v1/v2/v3 分别在后续 step 9/10/11 使用；05r2 的 v1/v2 分别在后续 step 2/3 使用。通信审计逐项核对了模型输入、会话、版本、候选证明步骤和生成概率。01r1 核对了 12 组生成记录，05r2 核对了 4 组，均无缺口。相同输入、版本和输出的 value 调用可能有多个等价匹配，不据此声称唯一请求配对。

每条学习回执的 LoRA、value head、optimizer 三组前后哈希均变化，上一条 after 与下一条 before 连续。真实首末快照经安全张量解码检查有限值，并与首末回执哈希一致；累计 optimizer step 为 3 和 2。快照内的学习回执还与 CPU 保存的回执逐条相等，所有更新都发生在尚未证明完成时。

初次五个 launcher 的启动时间相差约 5.397 秒，02/03/04 的 observer 区间重叠，支持多个 session 搜索同时推进。GPU actor 将模型调用串行执行；本页不声称 GPU kernel 并行，也不把本地 launcher PID 当作独立采集的 Lean 子进程 PID。两个成功重试不能代替“成功 session 同时在线更新”的额外并发隔离验收。

本次没有重新逐字节哈希冻结的完整 7B base，没有实际执行 snapshot restore，也没有为每个中间更新保存单独张量快照；中间状态依靠连续回执哈希关联。未训练对照、能力提升或不同题目稳定成功率尚未建立。GPU 容器、镜像发布也不在上述成功结论中。
