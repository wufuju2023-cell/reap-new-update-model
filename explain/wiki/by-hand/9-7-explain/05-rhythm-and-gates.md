# 05 — 新节奏方法论：断言-测量-门-证据（四件套）

## 为什么慢下来反而快
过去几周最大的损耗来自"线太多"：通道、恢复、文档、实验、复现同时泳。
固定节奏 = 每批只回答一个科学断言；批间产出**证据文件**（push 到 GitHub 分支），
别人随时可读、将来可回看。

## 四件套模板（每批必填）
```
① 断言（一句话，可证伪）：
   e.g. "φ>0 的证据注入使 MCTS selection 偏向 φ-加权的先验候选"
② 测量（固定哪些变量、看什么指标）：
   固定题/预算/参数；指标 ±门（比如 ΔV 单调性、sol@budget、熵变化）
③ 门（进/退判定）：
   例如：3/3 通过 → 进入下一线；1/3 → 回退调整（先小步再承认）
④ 证据（写盘+push）：
   milestone md 落 /explain/wiki/by-hand/…，附脚本可重跑
```

## 每周锚点（防迷失）
- 周一开始：写"本周主线一句 + 与 V1 问题的关系"至进度板顶栏。
- 周中保持：同一主线连续推进（并行线只能"冻结"不得"抢救式并行"）。
- 周末回望：更新 `v1-1-9-7-experiment-1/README` 的"阶段表 + 下一步"。

## 黄金三角（做任何长跑前自检）
1. 环境可复刻（任何人照 README 能跑）？
2. 测量可重复（同一系统同一输入同一输出，或分布带误差）？
3. 证据可回看（每个数字都能定位到脚本+md+sha）？
缺一角 → 先不扩规模。

## 与 V1 教训的耦合（scaling-plan-1 七条映射，防重犯）
- 先诊断后扩张：任何新规模前重跑 E1 门（sd=0 / 协议自检）。
- 评估集决定结论：标注 family-matched；不将 3 题外推。
- "已训练≠可复刻"：每个 release 记录契约（sha/指纹/参数）再谈结论。
- 长时运行工程化：断点+COMPLETE 门+防覆盖 guard 都在（checkpoint 体系已用）。
